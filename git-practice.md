# Git Practice

Today I learned how Git works.

Git Command    What it is used for
-----------    --------------------
- git clone  - To copy a GitHub repository to your computer
- git status - To see what has changed
- git add    - Tell Git what you want to save
- git commit - Save a version locally
- git push   - Send your changes to Github
- git pull   - Get changes from Github
- git log    - See your history
- git diff   - See exactly what changed
- git branch - Work with different branches
- git switch - Move between branches
- git merge  - Combine branches

# Cybersecurity-Notes

This repository is my personal collection of cybersecurity notes, resources, and lessons learned as I continue developing my skills in cybersecurity.

I’m using this repository to:

- Track my learning progress over time
- Document concepts, tools, commands, and techniques that I learn
- Keep useful references and examples in one place
- Record things that I find challenging or need to revisit
- Build a personal knowledge base that I can refer back to in the future

Some of these notes come from hands-on labs, including Hack The Box, personal projects, and cybersecurity training. Others are based on concepts and tools that I encounter while studying and practicing.

These notes are primarily for my own learning and reference, but I’m keeping the repository public in case they are useful to someone else who is learning cybersecurity as well.

This is a work in progress, so the content will continue to grow and change as I learn.
